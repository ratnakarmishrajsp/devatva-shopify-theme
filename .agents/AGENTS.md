# Workspace Rules for Divyatva Shopify Theme

## 1. Automatic Git Commit and Push
- **Mandatory Workflow**: Immediately after making ANY edit, file creation, or code modification in this workspace, you MUST execute a `git add .`, `git commit -m "<descriptive message>"`, and `git push origin main`.
- **Zero Pending Changes**: Never leave uncommitted or unpushed changes. Ensure the GitHub repository (`ratnakarmishrajsp/devatva-shopify-theme`) is always 100% in sync with local edits.
